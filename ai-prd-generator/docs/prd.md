# Product Requirements Document — AI PRD Generator

**버전**: 1.0
**작성일**: 2026-03-13
**작성자**: 기획팀
**상태**: MVP 개발 중

---

## 1. Executive Summary

AI PRD Generator는 PM/기획자가 아이디어 한 줄을 입력하면 Claude AI가 구조화된 PRD 초안을 30초 안에 자동 생성하는 웹 서비스입니다.

**핵심 가치**: PRD 초안 작성 시간을 2~4시간에서 30초로 단축하여, PM이 문서 작업보다 제품 전략에 집중할 수 있도록 합니다.

---

## 2. Problem Statement

### 현재 Pain Points

1. **시간 소요**: PM이 처음 PRD를 작성할 때 평균 2~4시간 소요
2. **공백 페이지 문제**: 처음 시작하는 빈 문서 앞에서 막막함을 느끼는 경험
3. **누락 섹션**: 중요 섹션을 빠뜨리거나 일관성 없는 구조
4. **반복 작업**: 매번 비슷한 형식의 문서를 처음부터 작성

### 기회

AI가 PRD 초안 작성을 지원하면 PM은 검토·개선에 집중할 수 있어 전반적인 문서 품질과 속도가 향상됩니다.

---

## 3. 목표

### 비즈니스 목표
- PRD 작성 초기 진입 장벽 제거
- PM의 핵심 업무(분석, 의사결정) 집중 시간 확보

### 제품 목표
- PRD 초안 생성: **30초 이내**
- 필수 섹션 완성도: **8개 섹션 100% 포함**
- 사용자 만족도: **4점 이상 / 5점**

---

## 4. 기능 요구사항 (MVP)

### F001 — 아이디어 입력 폼

**우선순위**: P0 (MVP 필수)

| 항목 | 내용 |
|------|------|
| 기능 설명 | 사용자가 서비스 아이디어, 타겟 사용자, 산업군을 입력하는 폼 |
| 입력 필드 | `idea` (필수), `targetUser` (선택), `category` (선택) |
| 입력 제한 | idea: 1~500자, 나머지: 0~200자 |
| 유효성 검사 | idea 누락 시 에러 메시지 표시 |
| UX | 입력 중 글자 수 카운터 표시 |

**수락 기준**:
- [ ] idea 필드가 비어 있으면 제출 불가 및 안내 메시지 표시
- [ ] 폼 제출 시 로딩 상태 즉시 표시
- [ ] 모바일 환경에서도 정상 동작

---

### F002 — AI PRD 자동 생성

**우선순위**: P0 (MVP 필수)

| 항목 | 내용 |
|------|------|
| 기능 설명 | Claude API를 이용해 구조화된 PRD 초안 자동 생성 |
| API 엔드포인트 | POST /api/generate-prd |
| 처리 시간 목표 | 30초 이내 |
| 출력 형식 | 8개 필수 섹션 포함 Markdown |
| 에러 처리 | API 오류, 타임아웃 시 사용자 친화적 에러 메시지 |

**생성 PRD 필수 섹션**:
1. Executive Summary
2. Problem Statement
3. Target Users & Personas
4. Goals & Success Metrics
5. Core Features (MVP)
6. User Stories
7. Technical Considerations
8. Risks & Mitigation

**수락 기준**:
- [ ] 30초 이내 PRD 초안 생성
- [ ] 8개 필수 섹션 모두 포함
- [ ] 입력 아이디어와 관련성 있는 내용 생성

---

### F003 — 섹션별 재생성

**우선순위**: P1 (MVP 이후)

| 항목 | 내용 |
|------|------|
| 기능 설명 | 마음에 들지 않는 개별 섹션만 AI에게 재생성 요청 |
| UI | 각 섹션 우측에 "재생성" 버튼 |
| 동작 | 해당 섹션만 새로 생성하여 교체 |

---

### F004 — Markdown 내보내기

**우선순위**: P1 (MVP 이후)

| 항목 | 내용 |
|------|------|
| 기능 설명 | 생성된 PRD를 .md 파일로 다운로드 |
| 파일명 | `prd-{아이디어-첫-단어}-{YYYYMMDD}.md` |
| 동작 | 버튼 클릭 시 즉시 다운로드 |

**수락 기준**:
- [ ] 생성된 PRD가 있을 때만 다운로드 버튼 활성화
- [ ] 다운로드된 파일이 유효한 Markdown 형식

## 5. 비기능 요구사항

| 항목 | 요구사항 |
|------|---------|
| 성능 | PRD 생성 응답 시간 30초 이내 |
| 반응형 | 모바일, 태블릿, 데스크탑 지원 |

## 6. Out of Scope (MVP 제외)

- 사용자 계정 및 로그인
- PRD 저장 및 이력 관리
- 팀 협업 기능
- PRD 템플릿 커스터마이징
- PDF 내보내기

## 7. 의존성 및 제약

- **Anthropic API 의존**: Claude API 장애 시 서비스 불가
- **API 비용**: 생성당 약 0.01~0.05 USD (claude-sonnet-4-6 기준)
- **응답 시간**: Claude API 응답 시간에 따라 변동 (평균 5~15초)
