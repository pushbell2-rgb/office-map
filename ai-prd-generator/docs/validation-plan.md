# 검증 계획 — AI PRD Generator

**버전**: 1.0
**작성일**: 2026-03-13

---

## 1. 핵심 가설

### 가설 H1 (주요)
> "PM이 AI PRD Generator를 사용하면, PRD 초안 작성 시간을 **70% 이상** 단축할 수 있다."

- **측정 방법**: 수동 작성 시간(2~4시간) vs AI 생성 시간(목표 30초)
- **성공 기준**: 생성 시간 30초 이내 + 8개 필수 섹션 포함

### 가설 H2
> "PM은 AI가 생성한 PRD를 바탕으로 최종 문서를 작성할 의향이 있다."

- **측정 방법**: 사용자 인터뷰 + 만족도 설문
- **성공 기준**: 사용자 만족도 5점 만점 중 4점 이상

### 가설 H3
> "PRD에 필요한 입력 정보를 PM이 30초 이내에 제공할 수 있다."

- **측정 방법**: 입력 완료 시간 측정
- **성공 기준**: 입력 완료 시간 평균 60초 이내

---

## 2. 성공 지표 (KPI)

| 지표 | 목표값 | 측정 방법 | 측정 시점 |
|------|--------|----------|---------|
| PRD 생성 응답 시간 | ≤ 30초 | 서버 타이머 | 기능 구현 직후 |
| 필수 섹션 완성도 | 8/8 섹션 | 생성 결과 검사 | 기능 구현 직후 |
| 사용자 만족도 | ≥ 4.0 / 5.0 | 사용자 설문 | 베타 테스트 |
| 에러율 | ≤ 5% | 서버 로그 | 배포 후 |
| 입력 완료 시간 | ≤ 60초 | 사용자 관찰 | 베타 테스트 |

## 3. 검증 단계

### Phase 1 — 기술 검증 (현재)

**목표**: 핵심 기능이 기술적으로 동작하는지 확인

| 검증 항목 | 방법 | 성공 기준 |
|----------|------|---------|
| AI 생성 응답 시간 | 로컬 테스트 10회 실행 | 평균 30초 이내 |
| 섹션 완성도 | 다양한 아이디어 5개 입력 후 결과 검사 | 8개 섹션 100% 포함 |
| 에러 처리 | API 키 누락, 잘못된 입력으로 테스트 | 적절한 에러 메시지 표시 |
| 모바일 반응형 | Chrome DevTools 모바일 시뮬레이션 | 레이아웃 깨짐 없음 |

**테스트 시나리오**:
1. "배달 앱 AI 메뉴 추천 서비스" — Food Tech
2. "원격 근무자를 위한 집중력 향상 앱" — Productivity
3. "시니어를 위한 디지털 리터러시 교육 플랫폼" — EdTech
4. "소상공인을 위한 재고 관리 자동화 도구" — B2B SaaS
5. "반려동물 건강 모니터링 IoT 서비스" — Pet Tech

---

### Phase 2 — 사용자 검증 (베타)

**목표**: 실제 PM이 사용했을 때의 경험과 가치 측정

**방법**: 베타 테스터 3~5명 모집 (PM/기획자 직군)

**검증 프로토콜**:
1. 참가자에게 아이디어 1개 제공 (또는 본인 아이디어 사용)
2. 서비스 사용 (개입 없음, 소요 시간 측정)
3. 생성된 PRD 품질 평가 (1~5점, 섹션별)
4. 사용 후 인터뷰 (5분):
   - "어떤 섹션이 가장 유용했나요?"
   - "실제 업무에 활용하시겠어요?"
   - "개선하고 싶은 점이 있나요?"

**설문 문항**:
- 전반적 만족도 (1~5점)
- PRD 완성도 (1~5점)
- 실제 업무 활용 의향 (Yes/No + 이유)
- 재사용 의향 (1~5점)
- 개선 요청 사항 (자유 기술)

---

### Phase 3 — 반복 개선

**목표**: 검증 결과 기반 제품 개선

- 가설 검증 결과 → 기능 우선순위 재조정
- 사용자 피드백 → UX 개선
- 에러 패턴 분석 → 안정성 개선
