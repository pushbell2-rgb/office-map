## 2. 사용자 여정 (User Journey)

### 메인 여정 — PRD 생성

```
[인식] 아이디어 회의 직후
   → [접속] 서비스 URL 방문
   → [입력] 아이디어, 타겟 사용자, 카테고리 입력
   → [대기] AI 생성 중... (로딩 표시)
   → [확인] 생성된 PRD 검토
   → [활용] Markdown 다운로드 → 노션/문서 도구에 붙여넣기
```

**소요 시간**: 약 2~3분 (입력 1~2분 + AI 생성 30초 이내)

## 3. 사용자 스토리

### Epic 1: PRD 생성

**US-001** (P0)
> **As a** PM,
> **I want to** 서비스 아이디어를 입력하면 AI가 PRD 초안을 자동 생성해주기를 원한다,
> **So that** 빈 문서 앞에서 막막함 없이 PRD 작성을 바로 시작할 수 있다.

수락 기준:
- [ ] 아이디어를 입력하고 "PRD 생성" 버튼을 클릭하면 30초 이내에 PRD가 생성된다
- [ ] 생성된 PRD는 8개 필수 섹션을 모두 포함한다
- [ ] 생성 중 로딩 상태가 표시된다

---

**US-002** (P0)
> **As a** PM,
> **I want to** 타겟 사용자와 산업군을 추가로 입력할 수 있기를 원한다,
> **So that** 내 아이디어에 더 맞춤화된 PRD를 받을 수 있다.

수락 기준:
- [ ] 타겟 사용자 필드와 카테고리 필드를 선택적으로 입력할 수 있다
- [ ] 추가 정보가 있을 때 PRD 내용의 구체성이 높아진다

---

**US-003** (P0)
> **As a** PM,
> **I want to** 아이디어 필드를 비워두고 제출했을 때 명확한 안내를 받기를 원한다,
> **So that** 무엇을 입력해야 하는지 즉시 알 수 있다.

수락 기준:
- [ ] idea 필드가 비어 있으면 제출 버튼이 비활성화되거나 에러 메시지가 표시된다

---

### Epic 2: PRD 활용

**US-004** (P1)
> **As a** PM,
> **I want to** 생성된 PRD를 Markdown 파일로 다운로드하기를 원한다,
> **So that** 노션, Confluence 등 도구에 바로 붙여넣을 수 있다.

수락 기준:
- [ ] "Markdown 다운로드" 버튼 클릭 시 .md 파일이 즉시 다운로드된다
- [ ] PRD가 생성되지 않은 상태에서는 다운로드 버튼이 비활성화된다

---

**US-005** (P1)
> **As a** PM,
> **I want to** 마음에 들지 않는 섹션만 다시 생성하기를 원한다,
> **So that** 전체를 새로 생성하지 않고 부분적으로 개선할 수 있다.

수락 기준:
- [ ] 각 섹션에 "재생성" 버튼이 있다
- [ ] 버튼 클릭 시 해당 섹션만 새로운 내용으로 교체된다

---

### Epic 3: 에러 처리

**US-006** (P0)
> **As a** 사용자,
> **I want to** AI 생성 오류 발생 시 명확한 안내를 받기를 원한다,
> **So that** 무슨 문제가 생겼는지 이해하고 다시 시도할 수 있다.

수락 기준:
- [ ] API 오류 시 "PRD 생성에 실패했습니다. 다시 시도해주세요." 메시지 표시
- [ ] 다시 시도 버튼이 표시된다
