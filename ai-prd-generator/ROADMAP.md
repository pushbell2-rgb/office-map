## 주요 의사결정 기록 (ADR)

### ADR-001: 프레임워크 없이 Vanilla JS 사용
- **날짜**: 2026-03-13
- **결정**: React/Vue 대신 Vanilla HTML/CSS/JS
- **이유**: PM 직군 프로젝트 — 프레임워크 설정보다 빠른 구현과 가독성 우선
- **트레이드오프**: 컴포넌트 재사용성 낮음, 대신 의존성 최소화

### ADR-002: Claude claude-sonnet-4-6 모델 선택
- **날짜**: 2026-03-13
- **결정**: claude-sonnet-4-6 모델 사용
- **이유**: 비용 대비 성능 최적, PRD 생성 품질 충분
- **트레이드오프**: Opus 대비 창의성 소폭 낮음, 응답 속도 빠름

### ADR-003: 단일 서버 아키텍처
- **날짜**: 2026-03-13
- **결정**: Express가 정적 파일(프론트)과 API를 모두 서빙
- **이유**: 배포 단순화, Railway 단일 서비스로 배포 가능
- **트레이드오프**: 프론트-백 분리 배포 불가, 대신 배포 복잡도 감소
